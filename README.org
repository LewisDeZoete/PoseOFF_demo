* PoseOFF Extraction Demo

This repo contains a simple, live demonstration of the PoseOFF extraction method using the [[https://cseweb.ucsd.edu/classes/sp02/cse252/lucaskanade81.pdf][Lucas-Kanade method]] of optical flow estimation in combination with [[https://docs.ultralytics.com/tasks/pose/][YOLO Pose]].

I've set this up to use [[https://docs.astral.sh/uv/][Astral UV]] to control the python environment and [[https://direnv.net/][direnv]] to control other environmental variables - for example your LSP. You can skip the latter, but I highly recommend at least trying UV.

*NOTE*: This demo only shows a visualisation of the extraction method, and does not contain and end-to-end human action anticipation framework.

** Installation

Clone this repo:

#+begin_src sh
git clone https://github.com/LewisDeZoete/PoseOFF_demo.git
#+end_src

Install UV to manage the python environment:
#+begin_src sh
curl -LsSf https://astral.sh/uv/install.sh | sh
#+end_src

Next, create the virtual environment and install the required dependencies. The dependencies are outlined in the [[file:pyproject.toml][project.toml]].

*** UNIX

**** Default
#+begin_src sh
cd PoseOFF_demo
# Create the virtual environment
python -m venv ./env # Default python venv

# Activate the environment
source ./env/bin/activate

# Install the requirements
python -m pip install -r requirements.txt
#+end_src

**** UV
If you've installed [[https://docs.astral.sh/uv/][Astral UV]], it's as simple as:
#+begin_src sh
cd PoseOFF_demo
uv sync
#+end_src

*** Windows
#+begin_src bash
cd PoseOFF_demo
python -m venv ./env
# Activate the environment, may change depending on if using CMD or PowerShell...
.\env\Scripts\Activate.ps1 # You should see (env) at the front of your prompt
# Install requirements, this may take some time!
python -m pip install -r requirements.txt
#+end_src

** Usage
Ensure that the virtual environment is active (=source env/bin/activate= for unix or =.\env\Scripts\Activate.ps1= for Windows).

Run the demo using default settings, simply use:

#+begin_src bash
python demo.py
#+end_src

*Press `q` to quit the demo.*

For help on the available arguments, use:

#+begin_src bash
python demo.py -h
#+end_src

Optional arguments are as follows:
| Argument flag       | Argument description                                                                                                                                   |
|---------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------|
| --input_type        | Input type must be in ['camera', 'video', 'frames'].                                                                                                   |
|                     | if 'camera', -c --camera_number must be set to an appropriate number (default 0).                                                                      |
|                     | If 'video', -i --input_path must be set to a video path (e.g. '.mp4').                                                                                 |
|                     | If 'frames', -i --input_path must be set to a folder containing video frames.                                                                          |
| -t, --threshold     | Confidence threshold below which pose keypoints will be discarded, between 0.0 and 1.0 (default 0.2).                                                  |
| -w, --window_size   | Width of square optical flow sampling window - must be an odd number - for example window_size=5 would result in a 5*5 pixel window (default: 5).      |
| -d, --dilation      | Dilation factor of sampling window, a higher dilation means a more spread sampling window (default: 3).                                                |
| -m, --mag_threshold | Optical flow magnitude threshold, limiting how large flow arrows will be (default: 1000).                                                              |
| -c, --camera_number | Camera number to stream from, this may require some trial and error... (default: 0).                                                                   |
| -i, --input_path    | If not using live webcam, pass the input path for videos of frames!                                                                                    |
| -s, --skip_frames   | Number of video frames in between each PoseOFF extimation - effectively controls framerate. A higher number means more frames are skipped (default: 0) |
| -o, --only_middle   | If passed, only draw the middle optical flow arrow on each pose keypoint - store_true (default: False).                                                |
| -r, --resize        | Amount to resize the output video by (default: 1)                                                                                                      |
| --write_video       | If passed, writes a video to the 'output/' folder                                                                                                      |
